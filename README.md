# SMA 2026 Methods for Dummies Resource Guide

A reading list on factor analysis and model fit, grouped by the questions researchers ask.
Companion to the Methods for Dummies session at the 2026 Southern Management Association annual meeting.

## Files

| File | What it is |
|:--|:--|
| `index.html` | The finished page. This is the file GitHub Pages shows to visitors. It is self-contained (styles and scripts are built in). |
| `index.qmd` | The editable source of the page (Quarto Markdown). |
| `styles.scss` | Colors and fonts used when the page is built. |
| `Williams-Hanna-2023-Factor-Analysis.pdf` | The chapter that the first resource links to. |

## Updating the page

`index.html` is generated from `index.qmd`, so edit the `.qmd` and then rebuild:

1. Install [Quarto](https://quarto.org/docs/get-started/) (free).
2. Edit `index.qmd`.
3. Run `quarto render index.qmd` in this folder. This rewrites `index.html`.
4. Upload the new `index.html` (and `index.qmd`) to this repository.
